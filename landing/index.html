Desktop app cho Windows

Tự động hoá Google Form hàng loạt, chạy local trên máy của bạn.

Extract cấu trúc form, cấu hình xác suất câu trả lời và submit nhiều lượt bằng Electron desktop app — không cần Google Forms API.

Tải bản mới nhất Xem cách cài

Tính năng chính

Một workflow từ extract đến submit

Auto extract

Đọc title, description, page và 12 loại câu hỏi từ Google Form respondent URL.

Tuỳ chỉnh xác suất

Thiết lập xác suất cho multiple choice, checkbox, dropdown và câu trả lời tuỳ biến.

Bulk submit

Chạy nhiều lượt submit với threads, delay ngẫu nhiên và stop graceful.

Monitoring realtime

Theo dõi success/fail, CPU, network và thread trong quá trình submit.

Copy Form MVP

Preview và copy best-effort sang target editable form, kèm cảnh báo unsupported types.

Chạy local

Dữ liệu runtime nằm trên máy của bạn; app desktop tự start backend local.

Cài đặt

Tải installer từ GitHub Releases

Landing page luôn trỏ tới trang Releases mới nhất để bạn chọn file installer phù hợp.

Mở GitHub Releases
  1. 1

    Tải Windows installer .exe mới nhất từ GitHub Releases.

  2. 2

    Cài app và mở từ Start Menu hoặc Desktop shortcut.

  3. 3

    Đảm bảo máy có Chrome/Chromium; app có thể tự resolve ChromeDriver khi khả dụng.

  4. 4

    Paste Google Form URL, preview cấu trúc và bắt đầu cấu hình.

Lưu ý an toàn

Không claim exact clone, không lưu binary trong repo

  • App chạy local desktop và không dùng Google Forms API chính thức.
  • Copy Form là best-effort; grid, file upload, rating, quiz/theme/branching có thể chỉ được cảnh báo hoặc hỗ trợ một phần.
  • Windows SmartScreen có thể cảnh báo cho tới khi app có code signing hoặc đủ reputation.
  • Installer được phát hành qua GitHub Releases, không commit binary vào repository.
